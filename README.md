# lilfeelz

Personal account for a terminal stack, small tools and device firmware.

- [based](https://github.com/lilfeelz/based): composable terminal workspace with persistent sessions
- [swole](https://github.com/lilfeelz/swole): strength-training log with one model over five runtimes
- [fmsh](https://github.com/lilfeelz/fmsh): shell commands from Apple's on-device model
- [totem](https://github.com/lilfeelz/totem): 38-key split keyboard firmware and keymap
- [SketchyVim](https://github.com/lilfeelz/SketchyVim): vim moves in macOS text fields

Docs: [docs.lilfeelz.org](https://docs.lilfeelz.org)
